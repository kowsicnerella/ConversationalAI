## 🐛 Known Issues & Solutions

### Issue 1: Assessment Not Loading

**Symptom:** Blank page on `/assessment`  
**Solution:** Check if `/api/assessment/generate` returns 200  
**Fix:** Ensure JWT token is valid and user is authenticated

### Issue 2: Learning Paths Not Showing

**Symptom:** Empty learning path selector  
**Solution:** Check if assessment is completed first  
**Fix:** Complete assessment before accessing learning paths

### Issue 3: AI Review Not Generating

**Symptom:** Lesson completes but no review shown  
**Solution:** Check if Gemini API key is configured  
**Fix:** Add `GEMINI_API_KEY` to `.env` file

### Issue 4: Milestone Modal Not Appearing

**Symptom:** Milestones achieved but no popup  
**Solution:** Check if `react-confetti` is installed  
**Fix:** `npm install react-confetti react-use`
