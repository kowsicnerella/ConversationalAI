### 3. Learning Path Orchestrator
**Purpose**: AI decides what user should learn next

**Decision Logic**:
```
Priority 1: Overdue vocabulary reviews (spaced repetition)
    ↓
Priority 2: Weak area reinforcement (performance < 70%)
    ↓
Priority 3: Next learning node (curriculum progression)
    ↓
Priority 4: Mixed review (variety & engagement)
```

**Factors Considered**:
- Recent performance data
- Weak/strong areas
- Vocabulary review schedule
- Learning velocity
- Time of day / session length
- Engagement patterns

**Status**: ⚪ Not yet implemented - Week 1 task

---

### 4. Adaptive Difficulty Engine
**Purpose**: Maintain optimal challenge level

**Algorithm**:
```python
if accuracy > 85% and fast_completion:
    difficulty += 0.1  # Increase challenge
elif accuracy < 60%:
    difficulty -= 0.15  # Make easier
elif 60% <= accuracy <= 70% with error_patterns:
    switch_to_related_concept()  # Lateral move
else:
    maintain_difficulty()  # Keep current level
```

**Status**: ⚪ Not yet implemented - Week 3 task

### 6. Vocabulary Mastery System
**Purpose**: Long-term vocabulary retention

**Features**:
- SM-2 spaced repetition algorithm
- Word network generation (related words)
- Context-based introduction
- Cross-activity reinforcement
- Memory techniques
- Mastery progression (new → learning → familiar → mastered)


## 🔄 User Journey Flow

### New User Onboarding
```
1. Sign Up
   ↓
2. Set Learning Goals
   - Daily time commitment
   - Learning focus (conversation, business, etc.)
   - Preferred topics
   ↓
3. Comprehensive Assessment
   - Conversational dialogue
   - Grammar test
   - Vocabulary test
   - Skills evaluation
   ↓
4. AI Generates Personalized Learning Path
   - Starting level determined
   - Weak areas identified
   - Custom roadmap created
   ↓
5. First Personalized Activity
   - Based on assessment results
   - Appropriate difficulty
   - Engaging content
```

### Daily Learning Loop
```
1. User Opens App
   ↓
2. Dashboard Shows
   - Current streak
   - Daily progress
   - Recommended activities
   - Vocabulary due for review
   ↓
3. AI Determines Next Activity
   - Check review schedule
   - Analyze recent performance
   - Consider weak areas
   - Select optimal activity
   ↓
4. User Completes Activity
   - Real-time performance tracking
   - Adaptive difficulty adjustment
   - Hint system available
   ↓
5. Performance Analyzed
   - Skill-specific metrics recorded
   - Error patterns identified
   - Mastery level updated
   ↓
6. Next Activity Determined
   - Based on performance
   - Maintains engagement
   - Optimal challenge level
   ↓
7. Repeat Until Daily Goal Met
```

### Weekly Review Cycle
```
1. Weekly Assessment
   - Quick skills check
   - Progress measurement
   ↓
2. Analytics Generated
   - Time spent analysis
   - Skill progression charts
   - Achievement highlights
   ↓
3. Recommendations Updated
   - Adjust focus areas
   - Update difficulty levels
   - Refresh learning path
```

## 💡 Key Principles to Remember

### 1. AI-First
**Every decision should be AI-driven**
- Content generation
- Difficulty adjustment
- Next activity selection
- Performance analysis

### 2. Personalization
**No two users should see the same content**
- User-specific activities
- Individual learning paths
- Custom difficulty levels
- Targeted practice

### 3. Continuous Adaptation
**System learns from user behavior**
- Real-time performance tracking
- Dynamic difficulty adjustment
- Weak area identification
- Learning velocity monitoring

### 4. Evidence-Based
**Follow research-backed methods**
- Spaced repetition for vocabulary
- CEFR framework for progression
- Interleaving for engagement
- Retrieval practice for retention

### 5. User Experience
**Make learning enjoyable**
- Engaging activities
- Visible progress
- Achievable goals
- Positive feedback

## 🚨 Common Pitfalls to Avoid

### 1. Hardcoding Content
❌ Don't: Create fixed activities
✅ Do: Generate all content dynamically

### 2. One-Size-Fits-All
❌ Don't: Same path for all users
✅ Do: Personalize based on performance

### 3. Ignoring Performance Data
❌ Don't: Generate activities randomly
✅ Do: Use analytics to inform decisions

### 4. Overwhelming Users
❌ Don't: Too many options or too hard
✅ Do: Maintain optimal challenge level

### 5. Neglecting Engagement
❌ Don't: Boring, repetitive activities
✅ Do: Varied, interesting, culturally relevant
