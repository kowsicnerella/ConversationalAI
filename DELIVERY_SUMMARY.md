## 📋 API Endpoints (19 Total)

### Conversations
- `POST /api/chat/conversations` - Create
- `GET /api/chat/conversations` - List all
- `GET /api/chat/conversations/:id` - Get specific
- `PUT /api/chat/conversations/:id` - Update
- `DELETE /api/chat/conversations/:id` - Delete

### Messages
- `POST /api/chat/conversations/:id/messages` - Send message
- `GET /api/chat/conversations/:id/messages` - Get messages

### Web Search
- `POST /api/chat/web-search` - Search web

### Memory
- `GET /api/chat/user-memories` - Get memories
- `POST /api/chat/search-memories` - Search memories

### Learning Context
- `GET /api/chat/user-learning-context` - Get context

### Analytics
- `GET /api/chat/analytics/conversations/:id` - Conversation stats
- `GET /api/chat/analytics/learning-statistics` - Learning stats
- `GET /api/chat/analytics/learning-insights` - Learning insights

### Search & Export
- `POST /api/chat/search-conversations` - Search
- `GET /api/chat/export/:id` - Export
